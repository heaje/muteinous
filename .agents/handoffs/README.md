# Branch-local unfinished-work handoffs

[`issue-20.md`](issue-20.md) records the M1.5 native-AST implementation evidence and supervisor follow-up. If an agent stops with other unfinished work and the next agent may not see GitHub Issue/PR comments, commit a focused `<issue-or-task>.md` **on the working branch** as described in [the handoff rules](../README.md#unfinished-work-handoffs).

Keep task status in Issues/PRs when available. Handoffs are temporary; delete them when work is resumed and completed. A branch-local note is not automatically present on `main`.
