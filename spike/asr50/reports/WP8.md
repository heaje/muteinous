## GPU execution evidence

**L5 (actual ASR inference with GPU computation)**: turbo was run on a 1,021.2-second repeated-clean WAV. The whisper process (PID 21544) logged `using Vulkan0 backend`, `Vulkan0 total size = 573.40 MB`, and encoder compute buffer allocation (55.35 MB). A separate PowerShell sampler filtered both PDH counter sets to that PID. Across 9 timestamped samples spanning 21 seconds (about 2.6-second interval), `GPU Engine` compute-engine utilization ranged 30.6–55.5%; process-filtered `GPU Process Memory\Dedicated Usage` was 1,117,040,640 bytes (~1.04 GiB). CLI logged 51 encoder runs; its total runtime was about 23.6 seconds. Thus backend-load lines alone were not the GPU proof; the process-filtered compute and memory counters were.

CPU control used the CPU-DL build on 102.1 seconds of repeated audio. Its separate PID-filtered sampler recorded 18 timestamped polls, all showing `matching_instances: 0` for both GPU Engine and GPU Process Memory. CPU control logged `no GPU found`. Process peak working set from the Windows process sampler was 408,743,936 bytes for Vulkan turbo and 987,090,944 bytes for CPU turbo. The GPU run itself was 24.4 seconds wall; the CPU control was 15.1 seconds. These are only run windows for counter context, not comparative benchmark timings. The first sampler attempt queried wildcard counters and got invalid-sample errors; the final sampler queried only per-PID instances and produced valid GPU samples.

## Explicit-GPU failure behavior (Vulkan build, small.en)

All three invalid/unavailable selections returned **exit code 0** and still transcribed “The banana rests beside Cobalt near the harbour.” This is silent CPU fallback and must be guarded against by the application when GPU selection is explicit.

| Test | Exact relevant log evidence |
|---|---|
| `GGML_VK_VISIBLE_DEVICES=5`, `-dev 0` | `ggml_vulkan: Invalid device index 5 in GGML_VK_VISIBLE_DEVICES.`; `CPU total size = 189.49 MB`; `whisper_backend_init_gpu: no GPU found` |
| `-dev 1` | `gpu_device = 1`; `CPU total size = 189.49 MB`; `whisper_backend_init_gpu: no GPU found` |
| `-dev 7` | `gpu_device = 7`; `CPU total size = 189.49 MB`; `whisper_backend_init_gpu: no GPU found` |

`ggml-diag.exe list` reports two devices: index 0 `Vulkan0` (RX 7900 XT), index 1 `CPU` (Ryzen 9 9900X). This explains why `-dev 1` selects CPU. Empty `GGML_VK_VISIBLE_DEVICES` did not hide Vulkan0 in an earlier probe. Explicit `-ng` logs `use gpu = 0` and `no GPU found`. The application should verify the selected backend and reject CPU execution for an explicitly requested GPU; success exit status and transcription text do not establish GPU execution.
