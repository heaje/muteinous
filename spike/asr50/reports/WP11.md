### VAD-masked v2 summary (<250 words)

- Masking followed by full CPU inference improved speech WER from 0.0720 to 0.0654 and reduced insertions from 30 to 21, but deletions rose from 16 to 19. Target recall/precision was 0.741/0.966. Silence/non-speech hallucination fell from 0.224 words/min and 5% of clips to zero.

This masks one existing hallucination but also skips real speech in `timing_noise_pink_-5_01`; its three reference words become deletions. Its unmasked hallucination was already a 3-substitution/11-insertion error, so aggregate WER happens to improve despite the false skip.
- Error review attributes most short-clip errors to low-SNR recognition and hallucinated phrase repetition. Isolated-word recognition is mostly correct, with one repeated hallucination. Long clips have occasional mid-phrase chunk artifacts, but only 3 of their 27 errors are deletions; chunk boundaries are not the main corpus-wide error source.

The v2 and v3 target P/R values use per-clip `score.target_metrics` followed by TP/FP/FN summation. Earlier v3 target values of 90.32/84.85% are superseded by the per-clip values shown above. Cross-clip token aggregation can match a target from one clip against a target in another, distorting TP/FP/FN. This correction changes target P/R only; no WER or S/D/I value changes for v1, v2, v2 masked/gated, or v3 raw/masked/gated.
