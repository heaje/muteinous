### Medium

2. **WP4 overstates CTranslate2 ROCm wheel availability and the extent of validation.** `reports/WP4.md:19, 26, 75` says CTranslate2 “provides ROCm release wheels” and describes the Windows ROCm path. The linked [Windows ROCm build guide](https://opennmt.net/CTranslate2/building_rocm_windows.html) exists and maps both RX 7900 XT and XTX to `gfx1100`, but its validation table names **RX 7900 XTX**, Windows 11 build 26200, ROCm 7.2.0, **Python 3.11**. It instructs users to install AMD `rocm_sdk_*` Python wheels, then **build CTranslate2 from source**; these are not prebuilt CTranslate2 ROCm wheels. Reword to distinguish AMD ROCm SDK wheels from CTranslate2 artifacts, and limit exact validation to the listed XTX/Python 3.11 setup. The guide's XT-to-gfx1100 mapping is documentary support, not a tested XT build or inference result.

3. **WP5 incorrectly leaves Moonshine Voice's model source/filenames unresolved.** `reports/WP5.md:39, 51-52` says the current package's exact fetch host and filenames remain unknown because its source was not inspected. Current [official download docs](https://moonshine-voice.readthedocs.io/en/latest/using/downloading-models/) explicitly show the STT host `https://download.moonshine.ai/model/medium-streaming-en/quantized_26_08_21` and component filenames including `adapter.ort`, `cross_kv.ort`, `decoder_kv.ort`, `encoder.ort`, `frontend.model.ort`, `frontend.weights.ort`, `streaming_config.json`, and `tokenizer.bin` (plus optional spelling files). Update the statement and identify the docs snapshot/revision as the provenance locator. The docs do not establish stable revision pinning or per-file SHA-256, so D144 integrity/provenance remains an open caveat.

   The other 12 hashes listed in the report match their WAVs. Fix the two report entries and confirm the generator's `ground_truth.json` carries the same corrected digests before treating the manifest as fully verified.

5. **WP1's Windows ML AMD GPU claim must remain provider-level, not exact-card support.** `reports/WP1.md:36,43` correctly notes that Microsoft Learn does not enumerate exact GPU SKUs, but phrases this as documented “provider/hardware family support” and suggests the route for this system.
