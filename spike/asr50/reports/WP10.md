VAD notably reduced hallucinations on this synthetic set and improved WER. The installed faster-whisper wheel contains `faster_whisper/assets/silero_vad_v6.onnx`, verified in the package; it is a bundled package asset, not separately downloaded. `vad_filter=True` used this asset.

All emitted words had finite timings (missing-alignment rate 0%). `word_timestamps=True` used faster-whisper cross-attention DTW alignment. Timing boundary error was **not successfully calculated**: score.py timing metrics require matched word pairs; this invocation did not establish per-clip matched alignments. No accuracy claim about boundary precision follows from the timestamps being present.

## Hardware support and errors

- **AMD GPU acceleration is unavailable in this runtime on this machine.** CTranslate2 installation is L2 evidence; `ctranslate2.get_cuda_device_count()` returned `0` (L3, CUDA enumeration only). CPU ASR inference succeeded (L5). None of these establishes AMD GPU support.
- `device='cuda'` raised exactly: `RuntimeError: CUDA failed with error CUDA driver version is insufficient for CUDA runtime version` at model construction. No GPU inference ran, so no L4/L5 GPU evidence.
- `device='auto'` constructed with `model.device == 'cpu'`, compute type `int8_float32`. It selected CPU in the absence of a supported CUDA device; this is observed resolution, not an observed silent fallback after a GPU inference failure.
- `device='rocm'` raised `ValueError: unsupported device rocm`; `device='hip'` raised `ValueError: unsupported device hip`. The exposed device API does not accept ROCm/HIP. No ROCm build was attempted because the HIP SDK is not installed and was not approved.
- GPU process counters were not sampled; VRAM is unavailable/null, not zero.

Practical D48 implication: Automatic selects CPU here, with no Radeon ROCm/HIP acceleration. Explicit CUDA did not silently fall back; it raised during construction, consistent with D49. This does not test GPU-op failure fallback on a supported GPU.

## Limitations and summary

Synthetic SAPI speech/noise is not representative game dialogue. Timing-boundary errors and GPU counters were unavailable. Warm measurements are same-process repeated passes, not a second process. The JSONL records' `installed_bytes` field was zero because the runner was refined after measurements; the independently measured full venv footprint above is authoritative. The reported `model.bin` hash is verified against WP7. Only approved local model weights were used.

**Summary (<300 words):** Offline faster-whisper 1.2.1/CTranslate2 4.9.1 inference succeeded on Python 3.14.10 win_amd64 with the approved Small.en CT2 artifact. Remaining limitations: no GPU backend/counters and timing-boundary score not produced. No further maintainer approval was needed for inference with the approved artifact.
